# Noctua NF-A4x105v (5V) — Pi Fan Control Reference

## Wiring (5V model — colors differ from the 12V Noctua fans)

| Pin | Color  | Function          | Connects to        |
|-----|--------|-------------------|---------------------|
| 1   | Black  | Ground (GND)      | Any Pi GND pin      |
| 2   | Yellow | +5V Vcc           | Pi 5V pin           |
| 3   | Green  | Tach / RPM sense  | GPIO16              |
| 4   | Blue   | PWM speed control | GPIO12              |

Note: the Pi's 5V pins are unregulated, direct from the PSU — no boost/regulation circuit needed for this fan (unlike 12V Noctua models).

## Fan control behavior

- PWM: GPIO12, 10kHz, via `gpiozero` (`PWMOutputDevice`)
- Tach: GPIO16, 2 pulses per revolution, via `gpiozero` (`DigitalInputDevice`)
- Duty cycle: 0% below 45°C, ramps 45°C → 80°C, minimum 30% once spinning (tune as needed), 100% at 80°C+

GPIO12 is one of the SoC's hardware-PWM-capable pins, so as long as the active
gpiozero pin factory is `lgpio` (the current Raspberry Pi OS default), the
signal is generated by hardware rather than timed in software — no `pigpiod`
daemon required (pigpio has been dropped from the Raspberry Pi OS repos).

**Frequency note:** Noctua's spec calls for 25kHz PWM, but the `lgpio`
backend caps out at 10kHz — requesting anything higher throws an error.
10kHz is well above the fan's response range and works fine in practice.

## Setup steps

```
sudo apt update
sudo apt install -y python3-gpiozero python3-lgpio

sudo cp fan_control.py /usr/local/bin/fan_control.py
sudo chmod +x /usr/local/bin/fan_control.py

sudo cp fan-control.service /etc/systemd/system/fan-control.service
sudo systemctl daemon-reload
sudo systemctl enable --now fan-control.service
```

Check it's running:
```
systemctl status fan-control.service
journalctl -u fan-control.service -f
```

## Files
- `fan_control.py` — the control script (gpiozero-based)
- `fan-control.service` — systemd unit (After=network-online.target, Restart=always)
